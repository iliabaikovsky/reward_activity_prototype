# Screenshot output

PNG лежат здесь после `npm run screenshots` или `npm run screenshots:minimal`.

**Полный реестр (id, sets, Figma, kindId):** [`docs/design/SCREENSHOT_CATALOG.md`](../design/SCREENSHOT_CATALOG.md).

```bash
npm run dev
npm run screenshots          # ~110 PNG (full)
npm run screenshots:minimal  # ~25 PNG (smoke)
```

Скрипты: [`scripts/capture-screenshots.mjs`](../../scripts/capture-screenshots.mjs), [`scripts/screenshot-shots.mjs`](../../scripts/screenshot-shots.mjs).
